# Git Workflow

Every team member must follow the workflow below.

## Step 1: Clone the Repository

```bash
git clone https://github.com/kedar1330/Python_batch_45_team.git
```

---

## Step 2: Move into the Repository

```bash
cd Python_batch_45_team
```

---

## Step 3: Create Your Own Branch

Replace `<your-name>` with your name.

Example:

```bash
git checkout -b ankita-feature
```

or

```bash
git checkout -b hemant-feature
```

---

## Step 4: Work Only Inside Your Assigned Folder

Example:

```
Ankita/
    palindrome.py
```

Do **NOT** modify files inside another member's folder.

---

## Step 5: Check Status

```bash
git status
```

---

## Step 6: Add Your Changes

```bash
git add .
```

---

## Step 7: Commit Your Changes

```bash
git commit -m "Added Palindrome Program"
```

Use meaningful commit messages.

Examples:

- Added Prime Number Program
- Added Fibonacci Program
- Fixed Armstrong Program
- Updated Calculator

---

## Step 8: Push Your Branch

```bash
git push origin ankita-feature
```

---

## Step 9: Create a Pull Request

1. Open GitHub.
2. Open your repository.
3. Click **Compare & Pull Request**.
4. Add a meaningful title.
5. Submit the Pull Request.

The Project Lead will review and merge your changes.

---

# Rules

- Create your own feature branch.
- Work only in your assigned folder.
- Do not modify another member's code.
- Do not push directly to the `main` branch.
- Always create a Pull Request.
- Write meaningful commit messages.
- Ensure your Python programs run without errors before submitting.
